# Pricing

Choose the plan that best fits your needs. All plans include our core features and world-class support.

## Plans

## Resource Pricing

<Tabs items={['Memory', 'Storage', 'Backups']}>
<Tab value="Memory">
### RAM Pricing
- **Standard Rate**: $3/GB/month
- **Pro Plan**: Same rate but billed hourly
- **Minimum**: 2GB per server
- **Maximum**: 16GB per server
</Tab>

<Tab value="Storage">
### Storage Pricing
- **SSD Storage**: Included with RAM
- **Additional Storage**: $0.10/GB/month
- **Minimum**: 10GB per server
- **Maximum**: 1TB per server
</Tab>

<Tab value="Backups">
### Backup Storage
- **Free Tier**: Not included
- **Pro Plan**: $0.015/GB/month
- **Retention**: Up to 30 days
- **Frequency**: Daily backups
</Tab>
</Tabs>

## Carbon Pro Benefits

### Enhanced Features
- Hourly billing for precise cost control
- Access to Carbon Marketplace
- Priority support queue
- Advanced monitoring tools
- Custom domain support
- API rate limit increase

### Resource Benefits
- Up to 7 concurrent servers (vs 3 on free tier)
- Automated backup system
- Dedicated IP addresses
- Premium server locations
- Resource scaling priority

### Support Benefits
- Priority ticket handling
- Discord priority support
- Advanced technical support
- Custom configuration assistance
- Migration assistance

## Billing Cycles

### Free Tier
- Monthly billing only
- Charged at the end of each month
- No minimum commitment

### Carbon Pro
- $9.99 monthly subscription
- Resources billed hourly
- Backup storage billed monthly
- Flexible payment methods
