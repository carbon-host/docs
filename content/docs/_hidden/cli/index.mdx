# Carbon CLI

The Carbon CLI (`@carbonhost/cli`) provides a command-line interface for managing your Carbon deployments and resources.

## Installation

<Tabs items={['npm', 'yarn', 'pnpm', 'bun']}>
<Tab value="npm">
```bash
npm install -g @carbonhost/cli
```
</Tab>
<Tab value="yarn">
```bash
yarn global add @carbonhost/cli
```
</Tab>
<Tab value="pnpm">
```bash
pnpm add -g @carbonhost/cli
```
</Tab>
<Tab value="bun">
```bash
bun add -g @carbonhost/cli
```
</Tab>
</Tabs>

## Quick Start

After installation, you can use the `carbon` command in your terminal:

```bash
# Initialize a new project
carbon init

# Deploy your application
carbon deploy

# List your deployments
carbon list

# Get deployment status
carbon status my-deployment
```

## Authentication

Before using the CLI, you need to authenticate:

```bash
carbon login
```

This will prompt you to enter your API key or open a browser for authentication.

## Common Commands

### Star Management

```bash
# Create a new Minecraft server (Star)
carbon star create survival-1 --type minecraft --version 1.20.1

# List all Stars
carbon star list

# Get Star status
carbon star status survival-1

# Stop a Star
carbon star stop survival-1

# Start a Star
carbon star start survival-1

# Delete a Star
carbon star delete survival-1
```

### Galaxy Management

```bash
# List available Galaxies
carbon galaxy list

# Get Galaxy status
carbon galaxy status us-east-1

# Scale Galaxy capacity
carbon galaxy scale us-east-1 --min 2 --max 5
```

### Constellation Management

```bash
# Create a Constellation
carbon constellation create minigames --stars 5

# List Constellations
carbon constellation list

# Scale Constellation
carbon constellation scale minigames --stars 10
```

## Configuration

The CLI can be configured using a `carbon.config.json` file in your project root:

```json
{
  "name": "my-network",
  "region": "us-east-1",
  "env": "production",
  "stars": {
    "default": {
      "type": "minecraft",
      "version": "1.20.1",
      "memory": "4G"
    }
  }
}
```
